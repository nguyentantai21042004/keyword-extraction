# Requirements for Standalone Keyword Extraction Algorithms
# ========================================================
# 
# This file contains all the necessary dependencies to run the standalone
# keyword extraction algorithms (spaCy + YAKE and Hybrid Ensemble).
#
# Installation:
#   pip install -r requirements_standalone.txt
#
# Note: Some packages may require additional system dependencies on Linux/Mac

# Core NLP and ML libraries
spacy>=3.5.0
yake>=0.4.8
rake-nltk>=1.0.6
scikit-learn>=1.3.0
numpy>=1.24.0

# System monitoring
psutil>=5.9.0

# Optional: For better performance
# torch>=2.0.0  # If using GPU acceleration
# transformers>=4.30.0  # For advanced BERT models

# Development dependencies (optional)
# pytest>=7.0.0  # For testing
# black>=23.0.0  # For code formatting
# flake8>=6.0.0  # For linting

# ============================================================================
# INSTALLATION INSTRUCTIONS
# ============================================================================
#
# 1. Create virtual environment (recommended):
#    python -m venv keyword_env
#    source keyword_env/bin/activate  # On Windows: keyword_env\Scripts\activate
#
# 2. Install dependencies:
#    pip install -r requirements_standalone.txt
#
# 3. Download spaCy model:
#    python -m spacy download en_core_web_sm
#
# 4. Test installation:
#    python spacy_yake_standalone.py
#    python hybrid_ensemble_standalone.py
#
# ============================================================================
# TROUBLESHOOTING
# ============================================================================
#
# Common issues and solutions:
#
# 1. spaCy model download fails:
#    - Check internet connection
#    - Try: python -m spacy download en_core_web_sm --force
#
# 2. YAKE import error:
#    - Ensure yake package is installed: pip install yake
#    - Check Python version compatibility
#
# 3. RAKE import error:
#    - Install rake-nltk: pip install rake-nltk
#    - May need to download NLTK data: python -c "import nltk; nltk.download('stopwords')"
#
# 4. scikit-learn import error:
#    - Install scikit-learn: pip install scikit-learn
#    - May need additional system libraries on Linux
#
# 5. psutil import error:
#    - Install psutil: pip install psutil
#    - On some systems may need: sudo apt-get install python3-dev
#
# ============================================================================
# VERSION COMPATIBILITY
# ============================================================================
#
# Tested with:
# - Python 3.8, 3.9, 3.10, 3.11
# - Ubuntu 20.04+, macOS 12+, Windows 10+
#
# Minimum requirements:
# - Python 3.8+
# - 4GB RAM (8GB recommended)
# - 2GB disk space for models
#
# ============================================================================
# PERFORMANCE NOTES
# ============================================================================
#
# - First run will be slower due to model loading
# - spaCy models are cached after first download
# - YAKE processing speed depends on text length
# - Ensemble method uses more memory but provides better accuracy
